# 🎤 Snaz Karaoke

Chrome Extension ที่ตัดเสียงนักร้องนำออกจากวิดีโอ YouTube แบบเรียลไทม์ ให้เหลือดนตรีและเสียงคอรัสไว้ร้องคาราโอเกะ

## ติดตั้ง (โหมดนักพัฒนา)

1. เปิด `chrome://extensions`
2. เปิด **Developer mode** มุมขวาบน
3. กด **Load unpacked** แล้วเลือกโฟลเดอร์ `extension/`
4. เปิดวิดีโอบน YouTube (ถ้าเปิดแท็บไว้ก่อนติดตั้ง ให้รีเฟรชหนึ่งครั้ง)
5. กดไอคอน 🎤 แล้วเปิดสวิตช์

## ปรับค่า

| ตัวเลือก | ความหมาย |
|---|---|
| ตัดเสียงร้อง | 0% = เสียงต้นฉบับ, 100% = ตัดเต็มที่ (ลด ๆ ลงหน่อยถ้าอยากได้เสียงไกด์) |
| เพิ่มความดังดนตรี | ชดเชยความดังที่หายไปพร้อมเสียงร้อง (0–12 dB) มี limiter กันเสียงแตก |
| ช่วงที่ถือว่าเป็นเสียงร้อง | แคบ = ตัดเฉพาะเสียงที่อยู่ตรงกลางเป๊ะ ดนตรีเหลือมาก · กว้าง = ตัดเสียงร้องสะอาดขึ้น แต่ดนตรีที่เอียงซ้าย/ขวาเล็กน้อยจะหายไปด้วย |
| เก็บเบสต่ำกว่า | ความถี่ที่ต่ำกว่านี้จะไม่ถูกตัด เพื่อเก็บเบสและกลองกระเดื่อง ซึ่งมักมิกซ์ไว้ตรงกลางเหมือนเสียงร้อง |
| เก็บเสียงแหลมสูงกว่า | ความถี่ที่สูงกว่านี้จะไม่ถูกตัด เพื่อเก็บฉาบ/ไฮแฮท |

## หลักการทำงาน

- content script ทำงานบน youtube.com โดยตรง จึงดึงเสียงจาก `<video>` ผ่าน Web Audio (`createMediaElementSource`) ได้ ไม่ต้องดาวน์โหลดคลิป
- `vocal-remover-worklet.js` แปลงเสียงเป็นความถี่ (STFT, FFT 2048, hop 512) แล้วดูทีละช่วงความถี่ว่าเสียงซ้ายกับขวา **เหมือนกันและเฟสตรงกัน** หรือไม่ ถ้าใช่ แปลว่าน่าจะเป็นเสียงที่อยู่ตรงกลาง (ปกติคือเสียงร้องนำ) ก็จะลดเฉพาะส่วน mid (L+R) ของช่วงนั้นลง ส่วน side (L−R) ไม่ถูกแตะ
- ดนตรีและคอรัสที่กระจายซ้าย-ขวาจะยังอยู่ และยังได้เสียงสเตอริโอเหมือนเดิม
- ถ้า AudioWorklet ใช้ไม่ได้ จะเปลี่ยนไปใช้โหมดสำรองแบบ L−R ด้วยฟิลเตอร์ของ Web Audio

### ข้อจำกัดที่ต้องรู้

- ใช้ได้ดีกับเพลงที่มิกซ์เสียงร้องไว้ตรงกลาง (เพลงส่วนใหญ่ในปัจจุบัน) ใช้ไม่ได้กับเพลงโมโน หรือเพลงที่ใส่ reverb/echo ให้เสียงร้องเยอะ (หางเสียงจะยังเหลืออยู่)
- เครื่องดนตรีที่อยู่ตรงกลางในช่วงความถี่เดียวกับเสียงร้อง (เช่น สแนร์ หรือโซโล่บางชิ้น) จะเบาลงไปด้วย
- เสียงช้ากว่าภาพประมาณ 45 ms จากการประมวลผล FFT

## ทดสอบ

```sh
npm test                 # ทดสอบ DSP ด้วย Node
npm install && npm run test:browser   # ทดสอบใน Chromium จริง + โหลด extension บนหน้า YouTube จำลอง
```

ลองเสียงกับไฟล์เพลงในเครื่องได้ที่ `demo/index.html` (ต้องเปิดผ่าน http server เช่น `python3 -m http.server` แล้วเข้า `/demo/`)
